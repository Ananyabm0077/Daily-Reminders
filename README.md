# 📅 Daily Reminder

A simple Daily Reminder web application built with **Node.js**, **Express.js**, **HTML**, **CSS**, and **JavaScript**. This application helps users create, manage, and organize their daily reminders through an easy-to-use interface.

---

## 🚀 Features

- ➕ Add new reminders
- 📋 View all reminders
- ✏️ Edit reminders
- ❌ Delete reminders
- 🎨 Simple and responsive user interface
- ⚡ Fast backend using Express.js

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- HTML5
- CSS3
- JavaScript

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/daily-reminder.git
```

### 2. Go to the project folder

```bash
cd daily-reminder
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

Or, if you have a start script:

```bash
npm start
```

### 5. Open the application

Visit:

```
http://localhost:3000
```

*(Replace the port if your application uses a different one.)*
